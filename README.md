# my-projects

A collection of independent tools:

- [Freshservice Customer SLA Dashboard](freshservice-customer-sla/README.md) — SLA performance by customer department.
- [Freshservice Team SLA Dashboard](freshservice-sla-dashboard/README.md) — SLA performance by team and technician.
- [Freshservice Ticket Report](freshservice-ticket-report/README.md) — active tickets grouped by customer.
- [Freshdesk Aged Ticket Tracker](Pending%20Tickets/README.md) — aged-ticket dashboard, CLI, and email alerts.

Each project has its own setup instructions. Keep local `.env` files and ticket exports private; only example configuration files belong in this repository.
